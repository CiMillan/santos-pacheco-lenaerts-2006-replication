Expected output:
always_c,   agent 0: None
disengaged, agent 0: ('cut', 1)  edge 0-1 left: False
disengaged, agent 1: None
engaged,    agent 3: ('link', 0)  edge 3-0 now: True

random,     agent 0: ('cut', 1)  edges 7 -> 6
bot ties untouched: True

Why: four agents in a line, 0-1-2-3, playing C, D, C, D, each with its own
bot (nodes 4-7, always C). Small enough to know every answer by hand.
  always_c: the bot never rewires, so nothing happens.
  disengaged, agent 0: its only agent neighbour is 1, a defector, so the
    bot tells 0 to cut 1, and the 0-1 tie is gone.
  disengaged, agent 1: its neighbours 0 and 2 are both cooperators (its
    bot doesn't count), so there's no defector to cut: None. Not a bug.
  engaged, agent 3: the cooperators are 0 and 2; 3 is already linked to 2,
    so the only choice is 0, and a 3-0 tie appears. This is the paper's
    "defector introduced to a cooperator".
  engaged, agent 1: it is already linked to both cooperators, so there's
    nobody new to introduce: None. Not a bug.
  random: a coin flip, blind to strategy. With this seed it came up
    "cut", and agent 0's only agent neighbour is 1, so 0-1 is cut (7 edges
    -> 6). With another seed it might come up "link" and add a tie to 2 or
    3 instead. Either way the edge count moves by exactly one.
  bot ties untouched: after every agent's bot acts, each agent still has
    its tie to its own bot. Bots only rewire agent-agent ties.
  A bug would show up as a disengaged cut to a cooperator, an engaged link
  to a defector, a link to a node already linked, or a missing bot tie.
