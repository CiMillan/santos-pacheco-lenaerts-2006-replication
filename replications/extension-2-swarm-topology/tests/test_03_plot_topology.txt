Then open plot_topology_demo.png and check by eye:
  - 4 rows (complete, single_scale, scale_free_random, scale_free),
    3 columns (imitation, swarm, swarm minus imitation).
  - First two columns use the same jet 0..1 colormap as ../../plot.py.
  - Third column is red-blue, white = 0: red where swarm cooperates MORE
    than imitation, blue where imitation cooperates more.
  - Spot-check one cell: if imitation is dark blue (~0) and swarm is
    light blue (~0.15) in the same cell, the difference cell should be
    pale red (~+0.15). If it came out blue, the subtraction is backwards.

Why: this only tests the DRAWING, not the science. The demo is tiny (n=100,
3 realizations, 50 generations, 3x3 grid) so it runs in seconds -- don't
read topology conclusions from it. The pale-red wash in the harsh
bottom-right corner of every difference map is the swarm "flicker floor"
(agents oscillating across the 0.5 threshold), not real cooperation --
see test_01_sweep_swarm.txt.
