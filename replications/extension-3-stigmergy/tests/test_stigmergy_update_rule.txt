Why: this is ../../../tests/test_update_rule.txt's setup (a defector next to one

the rule reads. Case 1: the neighbour earns nothing NOW, but its trace says 1,
so x switches with probability (1-0)/(1*3) = 1/3 -- the same rate the paper's
rule gives when the current payoff is 1. Case 2: the neighbour earns 1 NOW,
but its trace is still 0, so x never switches. A bug would show up as case 2
switching (the rule is reading current payoffs) or case 1 staying at 0 (it is
ignoring traces).
