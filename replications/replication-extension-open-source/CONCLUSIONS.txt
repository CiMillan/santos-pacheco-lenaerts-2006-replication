Does topology still matter once agents can read each other's code? No.
====================================================================
From open_source_experiment.py (run 2026-09-23, 1098 s). Output files:
run_log.txt, open_source_results.json, open_source_vs_imitation.png.
Reduced scale, same as the topology experiment: n=500 (n=200 for
complete), 10 realizations, 300+60 generations, 5x5 grid, same seeds.
Plain imitation numbers reused from

FINDING 1 -- the prediction holds: code-reading replaces the network
  Cooperation is 0.97-1.00 on every network, over the whole grid AND in
  the PD corner, where plain imitation is 0.000 everywhere at this scale.
  DefectBot is extinct in every run average (0.000 on every network).
  FairBot + PrudentBot hold 91-100% of agents in the PD corner (100% on
  complete, 91% on scale_free -- the rest is mostly CliqueBot).

FINDING 2 -- the topology ordering is gone, and slightly REVERSED
  Plain imitation: complete < single_scale < scale_free_random <
  scale_free (0.49 -> 0.65). Open-source: complete 0.995 > single_scale
  0.987 > scale_free_random 0.980 > scale_free 0.974. The gap is small
  (0.02), but it runs the other way, and in the same order on both
  measures.

FINDING 3 -- heterogeneity keeps CliqueBot alive
  CliqueBot share rises steadily with heterogeneity: 0.016 (complete) ->
  0.021 -> 0.087 -> 0.143 (scale_free). CliqueBot vs FairBot/PrudentBot is
  mutual D, so every surviving CliqueBot cluster that borders the
  FairBot/PrudentBot majority adds D actions. That is a plausible cause of
  the small reversal in Finding 2 (hypothesis, NOT tested).

FINDING 4 -- CooperateBot survives only outside the PD corner
  Whole grid: 12-15% CooperateBot. PD corner: ~0. Where T is high,
  PrudentBot's exploitation of CooperateBot pays enough for it to spread;
  elsewhere a CooperateBot next to FairBots earns the same as they do and
  imitation never removes it (neutral drift, no mutation).

CAVEATS
  - The outcome table is fixed and cost-free: code-reading programs get
    their advantage for nothing. The proof-cost experiment (next, per
    ARCHITECTURE.txt) is where the network effect could come back.
  - Reduced scale, 10 realizations. The 0.02 reversal is consistent in
    direction but small; not tested for significance.
  - Random 1/5-each start: code-readers begin at 60% of the population.
    Whether they can INVADE from a small minority is the separate
    follow-up already planned.

WHAT THIS MEANS FOR THE PhD FRAMING
  With transparency, cooperation no longer needs network structure: every
  network reaches near-full cooperation, even in the Prisoner's Dilemma.
  The heterogeneous networks that help plain imitators instead shelter a
  brittle "copy-recognising" program (CliqueBot) that doesn't cooperate
  with the robust ones. Relevant to Critch et al.'s Open Problem 2: in
  this setting, a population containing FairBots (unbounded DUPOCs) does
  converge to mostly agents that reward legible cooperation -- but only
  from a start where they're already common, and with free proofs.

OPEN FOLLOW-UPS
  - Proof cost per game for CliqueBot, FairBot, PrudentBot (Open Problem 9).
  - Invasion: start mostly CooperateBot/DefectBot plus a few code-readers.
  - Test the CliqueBot-cluster explanation of the small reversal.


FOLLOW-UP RESULT: proof cost -- the network effect comes back at high cost
==========================================================================
From cost_experiment.py (cost = 0.05, 0.2, 0.5, 1.0, run in parallel,
about 25 min each). Logs: run_log_cost_<value>.txt; results:
cost_<value>_results.json. Code-readers (CliqueBot, FairBot, PrudentBot)
pay `cost` per game. R=1, so cost=1.0 cancels the whole reward for mutual
cooperation. Values are (whole-grid mean / PD-corner mean):

cost     complete      single_scale  scale_free_random  scale_free
0.00     0.99 / 1.00   0.99 / 1.00   0.98 / 0.98        0.97 / 0.98
0.05     0.99 / 1.00   0.99 / 1.00   0.98 / 1.00        0.98 / 0.99
0.20     0.98 / 1.00   0.98 / 1.00   0.97 / 1.00        0.97 / 1.00
0.50     0.71 / 0.60   0.87 / 0.96   0.87 / 0.80        0.91 / 0.89
1.00     0.50 / 0.00   0.58 / 0.00   0.61 / 0.00        0.64 / 0.00
plain    0.49 / 0.00   0.57 / 0.00   0.62 / 0.00        0.65 / 0.00

FINDING 1 -- small costs change nothing
  Up to cost 0.2 the picture is the same as free code-reading: 0.97-1.00
  everywhere, DefectBot extinct, no topology ordering.

FINDING 2 -- at cost 0.5 the complete graph falls behind
  Complete drops to 0.71 (PD corner 0.60, DefectBot 40% of agents there);
  the structured networks hold 0.87-0.91. Complete's PD cells are exact
  multiples of 0.1 (0.5, 0.7) with 10 realizations: each run ends either
  all-cooperative or all-DefectBot -- winner takes all. On structured
  networks code-reader clusters survive. So the network helps again, the
  way it helps plain imitation. Among the structured networks the order
  isn't clean (single_scale has the best PD corner, 0.96), so this is
  "structure vs. no structure", not yet the paper's full ordering.

FINDING 3 -- at cost 1.0 it IS plain imitation again (sanity check)
  Code-readers are extinct in the PD corner; the numbers match plain C/D
  imitation to within 0.01-0.02 on every network, paper ordering
  included (0.50 -> 0.58 -> 0.61 -> 0.64). With cost = R, mutual
  cooperation between readers pays the same as mutual defection, so they
  lose to DefectBot and the game collapses to CooperateBot vs DefectBot,
  i.e. the original model. Good sign the code is right.

WHAT THIS MEANS FOR THE PhD FRAMING
  Transparency and network structure are substitutes: when reading code
  is cheap, the network doesn't matter; as it gets expensive, the network
  takes over again. The switch sits between cost 0.2 and 0.5 (20-50% of
  the cooperation reward). Relevant to Open Problem 9.

CAVEATS
  - Only 4 cost values; the threshold between 0.2 and 0.5 isn't located.
  - 10 realizations; at cost 0.5 the outcome is bistable per run, so cell
    values are coarse (steps of 0.1).
  - CliqueBot pays the same as a proof, which overcharges it.

OPEN FOLLOW-UPS
  - Finer costs between 0.2 and 0.5 (e.g. 0.3, 0.4) to find the switch.
  - A cost-curve figure like ../replication-extension-swarm-topology/figures/c1_curve.png.
