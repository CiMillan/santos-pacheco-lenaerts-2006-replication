Why: one run of each condition at the paper's game, T=2, S=-1 (a donation
game with b/c = 2), 500 agents on the single-scale network, 100
generations, same seed for all, so every condition starts from the same
network and the same 49.2% cooperators.
  none == ../../main.py: with no bots the new loop is exactly the base model,
    generation by generation. Anything that changes below comes from the
    bots alone.
  always_c: cooperative bot neighbours without rewiring don't save
    cooperation in this corner, as in the paper (Fig. S1A). The network
    doesn't change (3.95 ties per agent throughout).
  random: coin-flip rewiring, blind to strategy, does nothing for
    cooperation here. Ties drift up a little (3.95 -> 6.15) because an
    agent with no agent neighbours can only gain a tie, never lose one.
  engaged: defectors keep getting linked to cooperators, so cooperation
    collapses and the network gets much denser (3.95 -> 34.02).
  disengaged: the only condition that keeps cooperation alive in this
    corner (34.8%, where the base model gets 0). Ties drop to 0.64 per
    agent: most agents end up tied only to their bot. Part of the 34.8% may
    be strategies frozen in isolation rather than cooperation spreading
    -- checked in the full experiment, not here.
  This is one seed at one grid point; the prediction is tested by the
  full sweep.
