import sys

base = run(**args)

print('lam=1 identical to the paper run:', base == same)
print('final cooperation, paper rule :', round(base[-1], 3))
for lam in (0.5, 0.1):
    print(f'final cooperation, lam={lam:<4}:', round(run_stigmergy(**args, lam=lam)[-1], 3))
"

Expected output (exact for this seed):
lam=1 identical to the paper run: True
final cooperation, paper rule : 0.833
final cooperation, lam=0.5 : 0.55
final cooperation, lam=0.1 : 0.76

Why: the first line is the built-in check. With lam=1 every trace equals the
current payoff, so the stigmergy loop must reproduce ../main.py's run()
generation by generation, same seed -> the whole cooperation trace is
identical (True). False would mean the loop changed something besides the
traces (for example, drawing random numbers in a different order).
The other lines only show that lam changes the outcome. They are ONE run
each (one network, one start), so don't read a pattern into 0.55 vs 0.76 --
that needs many realizations and the (T, S) grid, which comes next.
