corner (T > 1, S < 0) and is all FairBot; (0.5, 0.5) isn't and is all
CooperateBot. Over the whole grid each program averages to 0.5; over the
PD corner only the FairBot point counts, so FairBot = 1.0. Same PD-corner
rule as summarize() in the topology experiment.
