Expected output:
nodes: 1000  bots: 500
new edges: 500
every bot has exactly 1 tie: True

Why: 500 agents on the single-scale network (the closest to the paper's
random graph), then one bot per agent, as in Shirado & Christakis (2020)
Experiment 1.
  1000 nodes = 500 agents + 500 bots.
  Exactly 500 new edges, one per bot, and every bot has degree 1: no bot
  is linked to another bot, and none has extra ties.
  Agent 7's bot is node 500 + 7 = 507, linked only to agent 7. Agents keep
  their original labels 0..499, so ../../payoff.py and ../../update_rule.py work
  on this graph unchanged.
  A bug would show up as more than 500 new edges, a bot with degree 0 or
  2, or a bot linked to the wrong agent.
